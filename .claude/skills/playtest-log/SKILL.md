---
name: playtest-log
description: Transfers playtest results (objective timer logs and the author's notes) into docs/OBJECTIVES.md without inventing values.
---
1. Ask the author for the timer log and notes for each tester.
2. Transfer the real values into the docs/OBJECTIVES.md table (P1, P2, P3, average, total).
3. Flag objectives outside 30–90 s, the intro if first input > 15 s or total > 60 s,
   and the overall total if outside 10–15 minutes.
4. Do not fill empty cells: list what is missing instead.
5. For each problematic objective, give 1–2 hypotheses, clearly marked as hypotheses.
